# セブンハーツ スタッフ登録ツール（LINE公式アカウント連携）

LINE公式アカウントを友だち追加した人に、スタッフ登録に必要な情報をLINE上のフォームで入力してもらい、
Googleスプレッドシートに自動で保存するツールです。日雇いアルバイトとしての雇用を前提にしています。

## 全体の流れ

```
友だち追加
  └─ 自動返信「スタッフ登録をする」ボタン
       └─ 登録フォーム（LINE内で開く）── 送信 → シート「スタッフ登録」に保存（ステータス：仮登録）
                                                 └ 本人にお礼メッセージ／管理者にメール通知
管理者が面談・選考 → シートのステータスを「採用」に変更
  └─ 本人に「書類を提出する」ボタンを自動送信（ステータス：書類依頼済）
       └─ 書類提出フォーム ── 送信 → シート「労務情報」＋Googleドライブに画像を保存（ステータス：書類提出済）
管理者が書類を確認 → ステータスを「稼働可」に変更
```

トーク画面で次の言葉を送ると、自動で返信します（それ以外のメッセージには返信しないので、担当者が手動でチャット対応できます）。

| 送信する言葉 | 返信内容 |
|---|---|
| 登録状況／ステータス | 現在のステータスと次にすること |
| 書類 | 書類提出フォーム（採用後のみ） |
| 登録／応募／変更 | 登録フォーム（登録済みの人は内容を変更できる） |

## 集める情報

### ① 登録フォーム（友だち追加の直後）→ シート「スタッフ登録」

| 区分 | 項目 |
|---|---|
| 基本情報 | 氏名、フリガナ、生年月日、性別 |
| 連絡先 | 携帯電話番号、メールアドレス、住所（郵便番号から自動入力）、最寄り駅 |
| 働き方の希望 | 職業区分、勤務できる曜日、勤務できる時間帯、希望エリア |
| 経験・スキル | 経験のある業務、資格・免許、語学 |
| ユニフォーム | 身長、服のサイズ、靴のサイズ、髪色、露出する位置のタトゥー |
| その他 | 自己PR・要望（任意） |
| 同意 | 個人情報の取り扱い、反社会的勢力ではないことの表明（同意日時を記録） |

年齢による自動チェック（労働基準法）
- **中学校卒業前**（15歳に達した日以後の最初の3月31日まで）は登録できません。
- **18歳未満**は深夜（22〜5時）を選べず、シートの「年齢による制限」列に注意書きが入ります（年齢証明書の備え付けが必要）。

### ② 書類提出フォーム（採用後）→ シート「労務情報」＋ドライブ

| 区分 | 項目 |
|---|---|
| 本人確認 | 国籍、本人確認書類の種類と画像、顔写真 |
| 外国籍の方 | 在留資格、在留期間の満了日、在留カードの表と裏、資格外活動許可（「留学」「家族滞在」の場合） |
| 給与 | 銀行名、支店名、口座種別、口座番号、口座名義（カナ） |
| 緊急連絡先 | 氏名、続柄、電話番号 |
| 税・労務 | 他社での勤務の有無、他社に扶養控除等申告書を出しているか |
| その他 | 健康上の配慮事項（任意）、守秘義務・SNS投稿禁止への同意 |

- 「留学」「家族滞在」で資格外活動許可がない場合は提出できません。「就労可否の確認事項」列に、確認すべきこと（週28時間以内など）が入ります。
- **マイナンバーは集めていません。** マイナンバーカードは表面だけを受け取り、裏面（個人番号）はアップロード欄が出ないようにしています。マイナンバーは法律上の安全管理措置が必要なため、源泉徴収票の作成などで必要になった時点で、別の方法で回収してください。

選択肢（希望エリア、経験業務など）は `gas/Options.gs` で変更できます。フォームはここから選択肢を読み込むので、フォーム側の修正は不要です。

## 構成

| 場所 | 役割 |
|---|---|
| `gas/` | Google Apps Script。LINEのWebhook、フォームから呼ばれるAPI、シートとドライブへの保存 |
| `liff/` | LINE内で開くフォーム（LIFF）。GitHub Pagesなどで公開する |
| `tests/` | 入力チェックのテスト（`node --test tests/*.test.js`） |

サーバーを借りる必要はなく、LINE・Google・GitHubの無料の範囲で動きます。

## セットアップ手順

### 1. LINE Developers でチャネルを用意する

[LINE Developers](https://developers.line.biz/console/) で、**同じプロバイダーの中に**次の2つのチャネルを用意します（プロバイダーが違うとユーザーIDが一致しません）。

1. **Messaging APIチャネル**：LINE公式アカウントに紐づいているもの
   - 「Messaging API設定」で **チャネルアクセストークン（長期）** を発行して控える
2. **LINEログインチャネル**：新しく作成
   - 「チャネル基本設定」の **チャネルID** を控える
   - 「LIFF」タブで LIFFアプリを追加
     - サイズ：Full
     - エンドポイントURL：手順4で公開するURL（例：`https://sevenhearts-staff.netlify.app/`）。手順4のあとで設定してもかまいません
     - Scope：`openid` と `profile` にチェック
     - 友だち追加オプション：On（Aggressive）
   - 作成された **LIFF ID** を控える
   - チャネルを「公開済み」にする

### 2. スプレッドシートと Apps Script を用意する

1. Googleスプレッドシートを新規作成する（例：「セブンハーツ スタッフ名簿」）
2. メニューの「拡張機能 > Apps Script」を開く
3. `gas/` の各ファイル（`Code.gs`、`Api.gs`、`Webhook.gs`、`Sheet.gs`、`Line.gs`、`Validation.gs`、`Options.gs`、`Diagnostics.gs`）を、同じ名前のファイルとして作成し、内容を貼り付ける
4. 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、`gas/appsscript.json` の内容を貼り付ける
5. 「プロジェクトの設定 > スクリプト プロパティ」に次の値を追加する

| プロパティ | 値 |
|---|---|
| `CHANNEL_ACCESS_TOKEN` | 手順1-1のチャネルアクセストークン |
| `LOGIN_CHANNEL_ID` | 手順1-2のチャネルID |
| `LIFF_ID` | 手順1-2のLIFF ID |
| `ADMIN_EMAIL` | 新規登録・書類提出を通知するメールアドレス（任意） |
| `PRIVACY_POLICY_URL` | 自社のプライバシーポリシーのURL（任意だが推奨） |

6. エディタで関数 `setup` を選んで「実行」し、表示される権限をすべて許可する。次のものが自動で作られます。
   - シート「スタッフ登録」「労務情報」
   - ドライブのフォルダ「セブンハーツ_スタッフ提出書類」
   - ステータス変更を検知するトリガー
   - Webhook用のトークン（実行ログに表示されます）
7. 「デプロイ > 新しいデプロイ > 種類：ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - デプロイ後の **ウェブアプリURL**（`…/exec`）を控える

> コードを変更したときは「デプロイを管理 > 編集 > バージョン：新バージョン」で更新してください（URLは変わりません）。

### 3. Webhook を設定する

1. LINE Developers の Messaging APIチャネルの「Webhook URL」に次の形式で入力する
   `ウェブアプリURL?token=手順2-6で表示されたトークン`
2. 「Webhookの利用」をオンにする
3. [LINE Official Account Manager](https://manager.line.biz/) の「応答設定」で
   - Webhook：オン
   - あいさつメッセージ：**オフ**（このツールが友だち追加時のメッセージを送るため）
   - チャット：オンのままでOK（担当者が手動で返信できます）

### 4. フォームを公開する

1. `liff/js/config.js` の `LIFF_ID` と `GAS_URL`（手順2-7のウェブアプリURL）を書き換えてコミットする
2. [Netlify](https://app.netlify.com/) に GitHub アカウントでログインし、「Add new site（Add new project）> Import an existing project > GitHub」でこのリポジトリを選ぶ
   - Branch to deploy：このリポジトリの既定ブランチ
   - Base directory・Build command：空欄
   - Publish directory：`liff`
   - 「Site configuration > Change site name」で名前を変えると、URL が `https://sevenhearts-staff.netlify.app/` のようになります
   - 非公開リポジトリのまま無料で使え、GitHub に変更をコミットすると自動で反映されます（リポジトリが公開なら GitHub Pages でも可）
3. このURLを、手順1-2のLIFFの「エンドポイントURL」に設定する

### 5. 動作確認

1. 自分のスマホで公式アカウントをいったんブロックし、ブロックを解除する（友だち追加と同じ扱いになります）
2. 届いたボタンから登録し、シート「スタッフ登録」に1行追加されることを確認する
3. その行のステータスを「採用」に変えると、書類提出のボタンが届くことを確認する

## 運用時の注意

- **シートとドライブのフォルダは、必要な担当者以外に共有しないでください。** 特に「労務情報」シートと提出書類のフォルダには、口座情報や身分証の画像が入ります。共有する場合は「スタッフ登録」シートだけを別のスプレッドシートに `IMPORTRANGE` で取り込むなどしてください。
- 列の見出しの文字は変更しないでください（列の追加や並べ替えは問題ありません）。管理用の列は「管理メモ」「書類確認者」「書類確認日」を使えます。
- このツールが送るメッセージ（登録のお礼、書類提出の案内、提出のお礼）は、LINE公式アカウントの月の無料メッセージ数にカウントされます。友だち追加時やキーワードへの応答は、無料の応答メッセージです。
- 退会したスタッフの個人情報は、保存期間を決めて削除してください（賃金台帳などの法定の保存期間に注意）。

## うまく動かないとき

Apps Script エディタで関数 `checkSettings` を選んで「実行」すると、スクリプト プロパティ・チャネルアクセストークン・
Webhook URL・シート・トリガーを点検し、問題のある項目と直し方を実行ログに表示します。
